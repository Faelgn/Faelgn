# Olá, eu sou Rafael Lucas! 👋

Técnico em Tecnologia da Informação e estudante de Ciência da Computação, com foco em infraestrutura, redes, administração de servidores Linux, acesso remoto seguro e automação de rotinas de TI.

Atuo com suporte e implementação de soluções práticas para melhorar a disponibilidade, a organização e a operação de serviços internos.

## Áreas de foco

- Administração de servidores Linux
- Redes, DNS, roteamento, NAT e firewall
- Acesso remoto via SSH e boas práticas de segurança
- Docker e Docker Compose para implantação de serviços
- Automação de tarefas de TI com Python e Bash
- Monitoramento, logs e execução de serviços com systemd
- Integração de bots e ferramentas internas para suporte e comunicação
